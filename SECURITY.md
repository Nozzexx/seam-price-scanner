# Security

If you find a security problem in the scanner or the S.E.A.M. site (for example a way to
read someone else's data, act as another member, or get a modified build to do something
the server should refuse), please report it privately:

- GitHub: **Security > Report a vulnerability** on this repository, or
- Discord: message a S.E.A.M. admin directly.

Please do not open a public issue for it. We will reply as soon as we can and credit you
if you would like.

Only download the scanner from this repository's Releases page, and check it as described
in the README. Builds from anywhere else are not ours.
